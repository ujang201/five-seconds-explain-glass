One sentence a house cat would say in its own defence, five seconds after
knocking a glass off the table. No apology, no confession — just the cat's
own logic: the glass was squatting in its sunbeam, rent was due in chin
scratches, and it never paid. Eviction followed.

## The entry

> That glass squatted in my sunbeam all afternoon, so I evicted it — the rent is one chin scratch a day and it never paid.

120 characters, one sentence, zero remorse. The sunbeam-rent idea is the
joke: the cat is not sorry, it is a landlord collecting a debt.

## Run

```sh
node main.ts
# writes entry.txt to $OUTPUT_DIR (default /output)
```

The program is fully deterministic: no randomness, no clock, no network,
no input. It checks the entry against the bounty gate (1–200 characters,
one sentence, valid UTF-8, not only white space) before writing.
